# VIX 市场信号面板

DeepSeek Harness 的美股市场信号插件，用于汇总六项情绪与技术指标、保存快照与操作记录，并提供可解释的市场观察建议。

> 仅供市场研究与风险教育，不构成投资建议或交易指令。

## 功能

- 六项市场信号：VIX、CNN 恐惧贪婪、标普 500 / 纳指 RSI、标普 500 / 纳斯达克 100 相对 200 日均线偏离。
- 总评分与信号状态：绿色代表底部观察，黄色代表关注，红色代表未触发。
- 最近 7 个真实交易日趋势图：移动鼠标可查看日期和值。
- 当前信号解读：展示支撑因素、风险与反证、后续观察条件。
- 数据源连通性：显示 VIX、CNN、标普 500、纳指、纳斯达克 100 的状态、行情时间与最近失败原因。
- 操作日志：可记录加仓/减仓、关联当时指标快照并回看。
- Agent 工具：`vix_dashboard` 支持当前信号、分析、快照历史与操作记录查询。

## 数据来源

| 指标 | 来源 |
| --- | --- |
| VIX、标普 500、纳指、纳斯达克 100 | Yahoo Finance |
| 恐惧贪婪指数 | CNN Business |

插件会优先通过配置的行情代理请求数据；代理不可用时会尝试直连公开来源。若本地网络无法访问上述站点，将保留历史快照，并在连通性卡片中显示本次失败原因。

## 安装

本插件面向 DeepSeek Harness 的 Cordis 插件运行时。

```bash
npm install
```

在 Harness 中安装或启用本目录的插件包后，侧边栏会出现“市场信号”入口。首次进入后点击“刷新指标”获取当前快照。

## 开发验证

```bash
node --check index.js
node --check client.js
```

## 目录

```text
├── index.js           # Host：行情采集、快照、分析与 Agent 工具
├── client.js          # Web 面板
├── cordis.patch.yml   # Cordis 插件配置
├── locale/            # 本地化资源
└── icon.svg           # 插件图标
```

## 使用边界

- 指标可能延迟、缺失或被数据源修订。
- 建议模块仅根据当前六项规则信号生成研究性解释。
- 请结合个人风险承受能力、资产配置和其他信息独立判断。
